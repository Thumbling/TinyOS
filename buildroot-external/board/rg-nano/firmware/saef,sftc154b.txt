# SAEF SFTC154B / ST7789V 240x240 panel used by the Anbernic RG Nano.
#
# The panel is driven through panel-mipi-dbi-spi. The 80-pixel horizontal
# back porch is described in the mainline device tree; this file only includes
# the controller bring-up.
#
# MADCTL matters twice here. panel-mipi-dbi always adds hback-porch (80) to the
# column address and vback-porch (0) to the row address, whatever MADCTL says.
# Only MADCTL 0xA0 (MV|MY) makes the controller address 320 columns by 240
# rows, so the 80-pixel offset lands inside the frame memory; with 0x00 the
# driver writes to columns 80..319 of a 240-column memory and every row is
# shifted, which looks like a skewed, flickering picture. 0xA0 is also the
# orientation that table lists for this offset pair. Do not change it without
# also changing hback-porch in the device tree.
command 0x01
delay 120
command 0x11
delay 120
command 0x3a 0x55
command 0x36 0xa0
command 0xb2 0x0c 0x0c 0x00 0x33 0x33
command 0xb7 0x35
command 0xbb 0x19
command 0xc0 0x2c
command 0xc2 0x01
command 0xc3 0x12
command 0xc4 0x20
command 0xc6 0x0f
command 0xd0 0xa4 0xa1
command 0xe0 0xd0 0x08 0x11 0x08 0x0c 0x15 0x39 0x33 0x50 0x36 0x13 0x14 0x29 0x2d
command 0xe1 0xd0 0x08 0x10 0x08 0x06 0x06 0x39 0x44 0x51 0x0b 0x17 0x14 0x2f 0x31
command 0x21
command 0x29
delay 20
